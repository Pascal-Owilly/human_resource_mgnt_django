Upload Excel File for Single/Bulk Contracts

Upload an Excel file with contract details to send to multiple candidates. Review the data below before submitting.

How It Works
Step 1: Upload Excel File

Select an Excel file that contains contract details for one or more candidates.

Step 2: Preview Data

Click the "Preview Data" button to see a preview of the contract details from the uploaded Excel file.

Step 3: Generate PDF

Once the data looks good, click the "Generate PDF" button to create a PDF of the contract details for all selected candidates.

Step 4: Submit

Finally, upon submission the generated PDF contracts are sent to the relevant candidates via email for them to sign.

Step 5: Admin Signature

Once the candidate has successfully submitted the signed document, the admin is notified to input the signature.

Step 6: Candidate Auto Registration

If the candidate is not yet registered in the system, after the admin submits the signed document, the candidate will be automatically registered, given the roles and position outlined in the Excel document, and assigned to the client as well.

Step 7: Candidate Receives Email to Set Password

The candidate will receive an email to set their password and successfully log in or download the Android app to start using the system.
