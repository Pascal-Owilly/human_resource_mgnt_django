How It Works
Step 1: Upload Excel File

Select an Excel file that contains contract details for one or more candidates.

Step 2: Preview Data

Click the "Preview Data" button to see a preview of the contract details from the uploaded Excel file.

Step 3: Generate PDF

The data will be submitted to the server for processing and PDF generation.

Step 4: Submission

Upon submission, the generated PDF contracts are sent to the relevant candidates as email attachments to be signed.
